*[GLIM]: GPU-accelerated LiDAR-IMU mapping and localization (koide3/glim), Jo's odometry and SLAM
*[RGL]: Robotec GPU Lidar, the Gazebo plugin that simulates the Velodyne on the GPU
*[RTF]: Real-time factor: simulated seconds per wall-clock second
*[EKF]: Extended Kalman filter (robot_localization), fuses GLIM and the IMU
*[TF]: ROS transform tree
*[DDS]: Data Distribution Service, the ROS 2 middleware (CycloneDDS here)
*[SDF]: Simulation Description Format, Gazebo's world and model format
*[URDF]: Unified Robot Description Format
*[ENU]: East-north-up axis convention
*[GNSS]: Global navigation satellite system (GPS)
*[Nav2]: The ROS 2 navigation stack
